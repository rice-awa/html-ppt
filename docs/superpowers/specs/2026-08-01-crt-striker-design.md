# 《辉光战机 · CRT STRIKER》设计规格

- 日期：2026-08-01
- 状态：已确认（grilling 讨论冻结版）
- 交付物：单个 HTML 文件（`slides/crt-striker.html`），走现有 Vercel 部署流程
- 一句话：CRT 显像管质感 × 横版飞机大战 × 3 个设计关卡 + 无限模式

---

## 1. 定位与交付

| 项 | 决定 |
|---|---|
| 形态 | 单个 HTML 文件，游戏本体 + 贴图生成 + 音频合成全部内嵌 |
| 位置 | `slides/crt-striker.html`，并在 `routes.json` 增加自定义路由（如 `/crt-striker`） |
| 部署 | 沿用仓库现有流程：`npm run build` → `public/` → Vercel |
| 联网 | **必须联网**：Phaser 3 走 jsdelivr CDN；CDN 加载失败时显示 CRT 风格错误屏 + 重试按钮，不允许白屏 |
| 断线兜底 | 错误屏需提供重试；不做离线降级（单文件无法内嵌 ~1.6MB 压缩的 Phaser） |

## 2. 技术栈

- **游戏引擎**：Phaser 3（最新 3.x，jsdelivr CDN），使用 Scene 系统、Tween、粒子、输入、相机
- **渲染**：WebGL 渲染器
- **后处理**：Phaser 3.60+ PostFX 自定义管线（CRT shader，GLSL 内嵌在文件内）
- **音频**：WebAudio 全程合成（SFX + chiptune BGM），零外部资源
- **持久化**：localStorage
- **无构建步骤**：文件可直接打开/部署；仓库 build.js 原样拷贝 slides → public

## 3. 画面与布局

| 项 | 决定 |
|---|---|
| 朝向 | **横版 16:9 横卷轴**（玩家向左/右推进，敌机从右侧/上方入场） |
| 逻辑分辨率 | 1280×720 |
| 缩放 | `Scale.FIT` 等比铺满窗口；不强制手机横屏（竖持也可玩，画面等比缩小） |
| 渲染 DPR | devicePixelRatio 上限 2 |
| 帧率目标 | 桌面 60fps；手机端自适应降特效 |
| 自动降级 | 持续低于 ~55fps 时：关闭 CRT shader 部分 pass、粒子数量减半 |

### 3.1 CRT 视觉效果（核心卖点）

Phaser WebGL 自定义 PostFX shader，包含：

- 扫描线（scanlines）
- RGB 通道错位（chromatic aberration）
- 暗角（vignette）
- 轻微桶形畸变（barrel distortion）
- 磷光辉光/余晖（phosphor glow）

附加规则：

- 设置中提供 **CRT 强度滑块**（默认适中，可关）
- 无 WebGL 环境：降级为无特效直接可玩，并提示
- 震动克制原则（见 §5）

## 4. 操作方案

| 端 | 移动 | 攻击 | 瞄准 | 其他 |
|---|---|---|---|---|
| 桌面 | WASD / 方向键 | **鼠标左键按住**（连射） | **鼠标右键按住** | Shift 放炸弹（B 备用）、P/ESC 暂停、M 静音、F 全屏、Space 为备用攻击键 |
| 手机 | 单指拖拽跟随 | 自动开火 | **第二根手指按住 = 瞄准** | 屏幕炸弹按钮 |

### 4.1 瞄准机制（手感核心）

- 平时：子弹朝正前方（卷轴前进方向），带散射锥
- 右键/第二指按住：显示 CRT 绿色虚线**瞄准射线**，子弹沿射线方向飞出，散射收束
- 射线方向 = 鼠标相对机头方向，**上下偏转限制 ±30°**（不做 360° 自由射击）
- 左右键可同时按住（输出 + 找角度）
- 游戏区内需拦截 `contextmenu`（禁止右键菜单）

## 5. 手感系统（全做，但有约束）

| 系统 | 规格 |
|---|---|
| 屏幕震动 | **必须克制**：低频、低振幅，仅用于命中/爆炸/受击/Boss 大招；设置中提供"震动开关 + 强度"两档控制 |
| Hitstop 顿帧 | 命中 30–60ms 极短停顿 |
| 粒子 | 击毁爆炸碎片、机尾引擎火焰、弹壳/火花 |
| 弹道拖尾 | 我方弹幕带拖尾 |
| 受击反馈 | 红闪 + 1.5s 无敌帧 |
| 连击计分 | 连击越高分数加成越大，飘分数字带 CRT 闪烁效果 |
| 擦弹（graze） | **做**：近距离擦过子弹加分数 + 维持连击；**只加分数，不给无敌/道具类奖励**，休闲玩家无视也能通关 |
| Boss 死亡慢动作 | 大爆炸时 ~0.3s 慢动作后恢复 |

## 6. 局内成长与生存系统

| 系统 | 决定 |
|---|---|
| 生命 | 3 条命，每次受弹 1 血 + 1.5s 无敌帧（无血条） |
| 死亡惩罚 | 爆机 + 火力降 1 级（不归零） |
| 炸弹 | 初始 2 颗，上限 5 颗；全屏清弹 + 大伤害；施放瞬间 0.5s 无敌 |
| 火力成长 | 捡 P 升级，最高 5 级；**每关 Boss 必掉 1UP 或 P** |
| 武器形态 | 两种可切换：**散射枪**（清兵）/ **激光**（打 Boss、与瞄准机制联动）；道具 W 切换 |
| 续关 | **无限续关**，死亡后从当前关卡开头重来；不做街机吞币 |
| 计分 | 分数榜只记录两类：无续关通关分数、最高分（见 §11） |

## 7. 三关关卡设计

通用结构：每关 4–6 波杂兵编排 + 中 Boss（仅 L2/L3）+ 关底 Boss；每关引入 1–2 种新敌机；敌机素材换色 + 数值缩放复用；关卡时长 L1 ≈2 分钟、L2 ≈2.5 分钟、L3 ≈3 分钟。

### 敌机图鉴（复用素材）

| 敌机 | 行为 |
|---|---|
| 侦察机 | 直线飞行，1–2 发点射 |
| 战斗机 | 正弦轨迹移动，瞄准射击 |
| 炮艇 | 慢速、厚血、扇形散射 |
| 自杀机 | 高速俯冲撞玩家 |
| 激光舰 | 蓄力后横向激光切屏（需上下穿缝） |

### 关卡表

| 关卡 | 主题 | 杂兵编排 | 中 Boss | 关底 Boss |
|---|---|---|---|---|
| L1「黄昏市街」 | 黄昏城市废墟，教学关 | 侦察机 + 战斗机；只教移动/射击/擦弹 | **无**（控制在 2 分钟内） | **「钢铁信天翁」重型轰炸机**：3 个弹型（瞄准点射 / 扇形散射 / 召唤 2 架侦察机），单阶段 |
| L2「铸造工厂」 | 敌人工厂内部，齿轮与熔炉 | 新增炮艇、自杀机；弹速明显加快 | **「双头压铸机」**：左右两座炮塔轮流射击，需切换目标 | **「铸造核心」**：旋转弹环 + 召唤炮艇；血线触发第二形态（核心裸露、弹幕加密） |
| L3「太空母巢」 | 太空要塞，最终战 | 新增激光舰（蓄力横切激光）；全类型混编 | **「守卫者方阵」**：4 台激光舰编队分波入场 | **「启示录」母舰核心**：3 阶段——激光扇形扫射 / 弹幕墙 + 追踪弹 / 狂暴期全屏弹幕 + 核心弱点暴露 |

### 难度曲线

- L1：弹速慢、弹幕间隙宽（新手可过）
- L2：弹速 +20%、新增自杀机
- L3：混合编排 + 弹幕墙

### 关卡解锁

- 顺序推进：只能顺序打
- 通关后可选关：已通关关卡可重玩刷分
- 通关 L3 → 解锁无限模式 + 显示通关结算/制作名单

## 8. 无限模式

| 机制 | 决定 |
|---|---|
| 结构 | 常规波次 + 周期 Boss：第 1–4 波常规 → 第 5 波 Boss → 第 6–9 波 → 第 10 波 Boss……循环 |
| 难度台阶 | 每 5 波：敌方 HP ×1.15、弹速 ×1.08、生成密度 ×1.1 |
| Boss 强化 | 每 2 轮随机获得 1 个强化：弹幕加密 / 更厚血 / 移动更快；Boss 从 3 个关底 Boss 中随机选 |
| 开局状态 | 每局从 1 级火力开始（公平起跑） |
| 结束 | 3 命用完即结束，记录"到达波数 + 分数" |
| 波次过渡 | 波次间 3 秒 CRT 风格横幅（如 "WAVE 7"），喘息 + 装弹时间 |
| 得分点 | 连击保持、擦弹、无伤击杀 Boss 有额外加成 |
| 解锁 | 通关 L3 后解锁，标题屏出现入口（未解锁显示 "???" 锁定） |
| 排行榜 | localStorage 本机 Top 5（姓名 + 分数 + 关卡/波数 + 日期），不做联网 |

## 9. 音频（WebAudio 全合成）

- **SFX**：激光（方波下滑）、爆炸（噪声爆发 + 低通）、拾取（琶音）、炸弹（低频轰鸣扫掠）、Boss 警报、UI 点击
- **BGM**：轻量 chiptune 音序器循环，每关不同（L1 舒缓 / L2 机械感 / L3 紧迫；Boss 战切紧张变奏）
- **自动播放策略**：首次点击/触摸时初始化 AudioContext
- **设置**：音乐 / 音效 / 总音量三档 + M 一键静音
- **CRT 嗡鸣**：可选低频（~55Hz）环境声，默认关闭（有人会烦）

## 10. 美术风格

- **程序化霓虹线框**：所有机体/子弹由代码绘制（Phaser Graphics 生成贴图），零外部图片资源
- 配色：玩家机绿色、敌机红橙、弹幕白/青；命中时敌机线框闪白
- 玩家机带引擎火焰粒子；Boss 多段描边 + 内部核心亮点
- 风格定位：《几何战争》× 老式示波器，CRT 弧面 + 磷光辉光下保持锐利（矢量不糊）
- 无限模式 Boss 强化用换色区分

## 11. 界面流程与持久化

| 屏 | 内容 |
|---|---|
| 开机动画 | 1.5s CRT 通电效果（横线展开 + 磷光闪烁），点击可跳过 |
| 标题 | 游戏名 + 「故事模式 / 无限模式（锁定显示 ???）/ 设置」+ 本机最高分；"PRESS START" CRT 呼吸闪烁 |
| 玩家名 | **开局输入玩家名**（首次启动显示输入框，默认 "PLAYER 1"，存 localStorage，之后可在设置中修改）；**不做街机 3 字母记名** |
| 选关 | 已通关可重玩，未解锁显示锁定 |
| 关卡过场 | "STAGE 1 — 黄昏市街" 大字 + 一行剧情小字，2 秒后开打 |
| 暂停 | P/ESC：继续 / 重新开始本关 / 设置 / 回标题；画面变暗 + "PAUSED" 扫描线字；**窗口失焦/切标签自动暂停** |
| 结算 | 通关：分数 + 连击统计 + 关卡评价（S/A/B/C，基于无伤/擦弹/时间）；Game Over：分数 + 波数（无限模式） |
| 通关 | L3 通关显示制作名单 + 无限模式解锁提示 |

**localStorage 持久化内容**：
1. 设置：CRT 强度、音乐/音效/总音量、静音、震动开关 + 强度
2. 进度：已通关关卡、无限模式解锁
3. Top 5 高分（姓名 + 分数 + 关卡/波数 + 日期）

## 12. 性能、兼容性与验证

| 项 | 决定 |
|---|---|
| 浏览器 | 现代浏览器（Chrome/Edge/Firefox/Safari 近两年版本） |
| WebGL | CRT shader 前提；无 WebGL → 无特效可玩 |
| 体积预算 | 游戏代码 + 贴图生成 + 音频合成 ≈ 150–250KB；Phaser 走 CDN（不计入单文件） |
| 自动暂停 | 窗口失焦 / 切标签自动暂停 |
| 全屏 | F 键切换 |
| 验证 | 仓库已有 Playwright：冒烟测试（页面加载、标题屏渲染、模拟按键开始游戏、跑 10 秒不死机）+ 截图检查 CRT 效果 |

## 13. 实施顺序（后续参考，本轮不实施）

1. 骨架：单 HTML + Phaser CDN 引入 + 加载错误屏 + 标题屏 + 玩家名
2. CRT PostFX shader + 强度设置
3. 玩家机（移动/攻击/瞄准/炸弹/武器形态）→ 手感模块（震动/Hitstop/粒子/擦弹）
4. L1 完整流程（波次 → Boss → 结算）→ L2 → L3
5. 无限模式 + 难度台阶 + 排行榜
6. WebAudio SFX + BGM
7. 性能降级、失焦暂停、Playwright 验证
